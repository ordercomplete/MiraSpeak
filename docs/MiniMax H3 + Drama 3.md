**Так, твоє залізо (3× RTX 3090 = 72 ГБ VRAM + 128 ГБ RAM) ідеально підходить.** Це один з найкращих споживчих сетапів для локального пайплайну.

### 1. Встановлення та використання MiniMax H3 + Drama 3

#### MiniMax H3 (відео)
- **Рекомендований шлях**: ComfyUI ≥ 0.30.0 (нативна підтримка).
- Ваги (з `Comfy-Org/MiniMax-H3` на Hugging Face):
  - `minimax_h3_fl2va_pruned_int8_convrot.safetensors` (~19–21 ГБ) → `models/diffusion_models/`
  - `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` (~15.7 ГБ) → `models/text_encoders/`
  - Video + Audio VAE (~5.6 ГБ разом).
- На **одній 3090** (24 ГБ) уже працює 15-секундний кліп 832×480 або вище з offload. З трьома картами можна:
  - Використовувати multi-GPU плагіни (наприклад, sequence parallel / Ulysses / Raylight / H3 MultiStream) — реальний прискорення ~2.5–3.1× на 4 картах, на 3 картах очікуй ~2.3–2.7×.
  - Або запускати паралельні генерації (різні сцени/варіанти).
- Запуск: `python main.py --listen 0.0.0.0 --port 8188 --disable-pinned-memory --fp16-intermediates` (і `--cuda-device all` для multi-GPU).
- Типові режими: Text-to-Video, Image-to-Video, Reference-to-Video (до 9 зображень + 3 відео + 3 аудіо).

#### Fish Audio Drama 3 (голоси)
- Офіційно потрібно ≥ 48 ГБ VRAM (FP8). У тебе 72 ГБ — комфортно.
- Встановлення (офіційне):
  ```bash
  conda create -n fish-speech python=3.12
  conda activate fish-speech
  # встановити з fish-speech repo з extra cu129 (або твій CUDA)
  hf download fishaudio/drama-3 --local-dir checkpoints/drama-3
  ```
- Запуск API-сервера: `python tools/api_server.py --listen 0.0.0.0:8080 --llama-checkpoint-path checkpoints/drama-3 --device cuda:0` (або `cuda:0,cuda:1,cuda:2` для multi-GPU).
- Є community-ноди для ComfyUI (ComfyUI-Drama3 / FishAudioDrama3), які дозволяють ганяти навіть на 8–16 ГБ завдяки offload експертів у RAM (у тебе 128 ГБ — ідеально). Можна тримати Drama 3 на одній 3090, а H3 на двох інших.
- Використання: текст + напрямки в квадратних дужках `[whisper, barely holding it together]`, multi-speaker (`<|speaker:0|>` тощо), voice cloning з референс-аудіо.

**Рекомендований пайплайн на твоєму ПК**:
1. Пишеш сценарій + напрямки → Drama 3 генерує якісні голоси (емоції, multi-character).
2. Подаєш аудіо як reference в H3 + зображення персонажів/стилю → отримуєш відео з синхронізованим звуком.
3. За потреби замінюєш нативне аудіо H3 на Drama 3 через ffmpeg або ComfyUI-ноди (краща якість голосу).
4. Для довгих історій — сегментами + склейка.

### 2. MosaiChunk — саме те, що потрібно для сюжетних ліній

**MosaiChunk** (arXiv 2610.02153, жовтень 2026) — механізм **spatio-temporal memory** для авторегресійних відео-моделей.

**Суть**:
- Звичайні моделі (в т.ч. H3 у streaming/AR-режимі) мають обмежене контекстне вікно. Коли об’єкт/обличчя/сцена виходить за межі вікна — деталі губляться, і при поверненні модель їх «вигадує» заново.
- MosaiChunk зберігає **мозаїку вибраних історичних KV-записів** (ключ-значення з попередніх чанків) у просторі й часі.
- Легкий роутер (навчений через self-distillation) вибирає, які саме фрагменти пам’яті тримати активними під фіксований бюджет.
- Генератор (backbone) залишається **замороженим** — змінюється тільки роутер.

**Для MiniMax H3**:
- Є спеціальна версія **RAVEN-adapted MiniMax-H3 (H3-AR)** + готовий router checkpoint.
- Код + ваги: [github.com/mosaichunk/MosaiChunk](https://github.com/mosaichunk/MosaiChunk) + Hugging Face `mosaichunk/MosaiChunk`.
- Підтримує довгі горизонти (сотні кадрів) зі збереженням ідентичності облич, об’єктів, деталей сцени при повторних появах.

**Як використовувати для сюжетних ліній**:
1. Генеруєш перший сегмент (з H3 + Drama 3).
2. MosaiChunk зберігає ключові KV (обличчя, одяг, предмети, освітлення).
3. Наступні сегменти отримують ці «спогади» як far-memory → персонажі, предмети, стиль залишаються консистентними навіть якщо вони зникали з кадру.
4. Можна робити prompt-driven revisits («повернутися до тієї ж кімнати / того ж персонажа через 30 секунд») або camera-driven (об’їзд камери 180° і назад).

Це саме те рішення проблеми consistency, якої не вистачає звичайному H3 на довгих історіях.

### Практична структура на 3×3090
| Компонент          | Карта(и)     | Примітка                          |
|--------------------|--------------|-----------------------------------|
| Drama 3            | 1× 3090     | або offload експертів у RAM      |
| H3 (основний)      | 1–2× 3090   | multi-GPU parallel для швидкості |
| MosaiChunk router  | на тій же   | легкий, майже не займає VRAM     |
| Пост-обробка       | CPU + RAM   | ffmpeg, ComfyUI                  |

**Висновок**:  
З твоїм залізом можна робити **повноцінні сюжетні короткометражки** локально: якісні емоційні голоси (Drama 3) + кінематографічне відео (H3) + довгострокова консистентність персонажів/об’єктів (MosaiChunk).  

Хочеш — можу дати покроковий гайд з конкретними командами встановлення, посиланнями на workflow-файли ComfyUI і прикладом сценарію з MosaiChunk.
