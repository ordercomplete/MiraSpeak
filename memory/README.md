# MiraSpeak — памʼять розробки (журнал змін)

Файли за датами. Кожен файл `YYYY-MM-DD.md` створюється у день першого запису,
всередині — записи з точним часом змін. Наступна доба → новий файл.

Порядок записів: від старих до нових, формат `- [HH:MM] текст`.

## Правила ведення журналу

1. **Записувати зміни в `memory/YYYY-MM-DD.md` до коміту** — щоб журнал не відставав
   від репозиторію (2026-10-20: зміни сесії 19–20.10 не були записані, довелося
   відновлювати журнал заднім числом).
2. **Після кожної правки `static/index.html` проганяти синтаксическую перевірку**
   витягнутого `<script>` (`node --check`) — 2026-10-20 через зайву `}` увесь
   фронтенд перестав виконуватись (кнопки, діалог, історія чатів були мертві,
   поки API працював).
3. Формат файлу: `# YYYY-MM-DD`, далі записи від старих до нових, у кожному —
   час, коміт (якщо є) і суть зміни.
